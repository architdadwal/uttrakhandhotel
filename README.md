# White Peak Homestay — demo website

A responsive four-page React + Vite website for a homestay in Pauri Garhwal, Uttarakhand.

## Run locally
1. Install Node.js 18+.
2. Extract the project.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Build for hosting
Run `npm run build`. Upload the contents of the generated `dist` folder to your hosting public_html directory.
